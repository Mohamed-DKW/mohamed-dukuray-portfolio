# Mohamed Dukuray — Portfolio

Portfolio personal para presentar mis proyectos y experiencia como desarrollador Full Stack. Está construido con Next.js y ofrece contenido en español e inglés.

**Portfolio:** [mohamed-dkw.github.io/mohamed-dukuray-portfolio](https://mohamed-dkw.github.io/mohamed-dukuray-portfolio/) · **LinkedIn:** [Mohamed Dukuray](https://www.linkedin.com/in/mohamed-dukuray/)

## Tecnologías

- Next.js 14, React 18 y TypeScript
- Tailwind CSS
- Framer Motion
- Embla Carousel

## Desarrollo local

Requisitos: Node.js 20 o posterior y npm.

```bash
npm ci
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Comprobaciones

```bash
npm run type-check
npm run build
```

## Despliegue

GitHub Actions genera una exportación estática y la publica en GitHub Pages al actualizar la rama `main`.
